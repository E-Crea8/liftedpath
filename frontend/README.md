# LiftedPath public site

Next.js application that renders the LiftedPath website. The repository README at the parent of this folder describes the theme, this app, and how they connect.

Vercel uses this directory as the project root.

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open http://localhost:3000. Set the values named in `.env.example` in `.env.local`. Do not commit that file.
